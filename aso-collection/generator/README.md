# Генератор скриншотов магазина

Веб-инструмент собирает русские витринные скриншоты из изображений приложения
и макета телефона. Скриншоты лежат в `public/screenshots/ru/`, форматы экспорта
— в `src/lib/store_formats.mjs`.

## Запуск

```sh
bun install
bun run dev
```

Откройте <http://localhost:3000>, выберите формат и скачайте отдельный слайд
или ZIP со всеми слайдами.

## Проверка

```sh
bun test
bun run build
```
